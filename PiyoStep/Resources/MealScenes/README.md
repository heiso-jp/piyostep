# Bundled piyo meal scenes

Five user-provided APNG scenes, finished.png, and piyo-meal-scenes.json are
installed together in this directory. Missing, invalid or corrupt assets fall
back to existing character art. Only piyo uses this catalog.

The supplied compact format is decoded directly: schemaVersion, width, height,
frameDurationMs, finishedImage, allowedActivities, scenes[{id,file,frameCount,
durationMs}]. Missing characterID means piyo only for this named manifest.

Parent-confirmed ranges (end exclusive): [0,20), [20,40), [40,60), [60,75),
[75,101). Each frame is 100ms: 2.0/2.0/2.0/1.5/2.6 seconds.

Activity mapping: eating = scene01 (small flap, mouth open like chewing);
resting = scene04 (eyes closed); cheering = scene02, scene03, scene05 (random).
Rice only decreases during eating, so the chewing clip is the base motion.
Each clip loops 3 times before the next pick; an activity change cuts the loop short. Game finished displays `finished.png` and stops selection.
macOS ImageIO verified all 101 frames, dimensions and delays in the built app bundle.

No GIF re-encoding, interpolation, cropping, rescaling of assets or recoloring.
ImageIO decodes APNG frames; UIImageView uses aspectFit for display. APNG decoded
frame count must match manifest. Verify composite pixels on an iOS device; that
has not been tested here. If ImageIO's APNG decode does not preserve the supplied
composites on target iOS, use the media team's PNG-frame variant instead.

An optional explicit sequence format is also supported per scene:
`encoding: "pngSequence"`, `files: ["scene01-000.png", ...]`,
`frameDurationsMs: [100, ...]`, `allowedActivities: ["eating", "resting", "cheering"]`.
All displayed frames must match manifest width/height. Files must be relative PNG
or APNG names, without traversal. Keep filenames unique if Xcode flattens copies.

The synchronized Xcode group imports additions; XcodeGen also scans PiyoStep.
All seven media/manifest resources were verified in the built app Bundle. No assets are
faked or silently generated by this code.
