The supplied compact format is decoded directly: schemaVersion, width, height,
frameDurationMs, finishedImage, allowedActivities, scenes[{id,file,frameCount,
durationMs}]. Missing characterID means piyo only for this named manifest.

[75,101). Each frame is 100ms: 2.0/2.0/2.0/1.5/2.6 seconds. All five gestures are
eligible for eating/resting/cheering. They are not classified as dedicated sleep
or completion clips. Game finished displays `finished.png` and stops selection.

No GIF re-encoding, interpolation, cropping, rescaling of assets or recoloring.

frame count must match manifest. Verify composite pixels on an iOS device; that
has not been tested here. If ImageIO's APNG decode does not preserve the supplied
composites on target iOS, use the media team's PNG-frame variant instead.

An optional explicit sequence format is also supported per scene:
`encoding: "pngSequence"`, `files: ["scene01-000.png", ...]`,
`frameDurationsMs: [100, ...]`, `allowedActivities: ["eating", "resting", "cheering"]`.
All displayed frames must match manifest width/height. Files must be relative PNG
